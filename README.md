# AgentCare

## Description
AgentCare is an agentic AI application built to process administrative patient requests.

## Architecture
- Built using Python and LLM clients.
- Handles workflow routing based on user input.

## How to Run It
1. Clone the repository.
2. Create a `.env` file based on `.env.example` and fill in your API keys.
3. Install dependencies: `pip install -r requirements.txt`
4. Run the application: `python main.py`
